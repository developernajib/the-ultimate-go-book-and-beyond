# System Design: Google Search - Web-Scale Search Engine

> The PageRank algorithm turned the hyperlink graph into a democracy: every link a vote. The engineering challenge was making that democracy answer in 200ms.

Web search is the largest information retrieval problem ever built. Indexing 50 billion web pages into a 1PB inverted index and answering 100,000 queries per second with sub-200ms latency requires every layer of the stack, crawling, indexing, ranking, and serving, to operate at a scale where most conventional approaches simply break. A single query fans out to thousands of index shards in parallel, each shard searches its portion of the index, and a coordinator merges and re-ranks the results, all within a budget measured in milliseconds.

The three hardest engineering challenges are: (1) keeping the index fresh through continuous crawling of billions of pages while maintaining a delta index that makes new content searchable within minutes rather than days, (2) two-phase ranking that separates fast recall (BM25 on each shard) from precise re-ranking (ML model combining PageRank, freshness, click signals, and personalization), and (3) scatter-gather query execution across 1,000+ shards where a single slow shard can blow the latency budget for the entire query.
