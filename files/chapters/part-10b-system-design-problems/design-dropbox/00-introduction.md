# System Design: Dropbox - Cloud File Storage and Sync

> The core insight behind Dropbox-style sync: files change in small chunks. Delta sync means syncing a gigabyte document after a typo costs kilobytes, not the gigabyte.

Dropbox is a deceptively simple product, "sync files across devices", built on some of the hardest problems in distributed systems. At 700 million registered users storing over an exabyte of data (Dropbox's Magic Pocket migration already involved 500 petabytes back in 2016), a system at this scale handles thousands of uploads per second and must keep every user's devices in near-real-time sync. The naive approach of uploading entire files on every change would be absurdly wasteful: a single-character edit to a 1GB presentation would re-transfer the entire gigabyte. Delta sync, powered by content-addressed 4MB blocks, reduces that to transferring only the one changed block.

The three hardest engineering challenges are: (1) conflict resolution when two offline devices edit the same file and then reconnect, (2) storage efficiency through block-level deduplication (early Dropbox famously deduplicated across users, then retreated to per-user dedup for privacy reasons, an instructive trade-off in itself), and (3) real-time notification propagation so that a file saved on one device appears on all others within seconds, even when those devices connect through different API servers.
