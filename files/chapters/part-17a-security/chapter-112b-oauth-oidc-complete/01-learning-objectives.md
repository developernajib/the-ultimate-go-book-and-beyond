## Learning Objectives

By the end of this chapter, you will understand:
- OAuth 2.0 flows and when to use each grant type
- OpenID Connect (OIDC) for authentication vs. authorization
- Implementing a complete OAuth 2.0 authorization server in Go
- Resource server JWT validation with JWKS rotation
- PKCE for public clients (SPAs, mobile apps)
- Token introspection, revocation, and refresh token rotation
- Social login integration (Google, GitHub, Microsoft)
- Security hardening: CSRF protection, token binding, DPoP
