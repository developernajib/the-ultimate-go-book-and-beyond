## Learning Objectives and Prerequisites

### Key Learning Objectives

By completing this capstone project, you will:

- Build a complete MLflow/Kubeflow-like ML platform from scratch in Go
- Implement experiment tracking, model registry, and model serving
- Design and implement a feature store with online/offline serving
- Create pipeline orchestration for ML workflows
- Implement A/B testing infrastructure for model comparison
- Build monitoring and observability for ML systems
- Handle multiple model formats (ONNX, TensorFlow, custom Go models)
- Implement data drift detection and model performance tracking
- Design scalable APIs for ML workloads
- Apply production-ready patterns for ML infrastructure


### Recommended Prerequisites

- Completed Parts 1-19 of this book
- Understanding of machine learning concepts (models, training, inference)
- Familiarity with distributed systems patterns
- Experience with gRPC and REST APIs
- Knowledge of time-series databases and metrics
