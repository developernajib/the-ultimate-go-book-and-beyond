## Features

- **Dynamic Routing**: Path, host, and header-based routing with wildcards
- **Plugin System**: Extensible middleware architecture
- **Load Balancing**: Round-robin, least connection, weighted random, IP hash, consistent hash
- **Authentication**: JWT, API Key, OAuth2, mTLS
- **Rate Limiting**: Token bucket algorithm with configurable limits
- **Circuit Breaker**: Automatic fault tolerance
- **Caching**: Response caching with TTL
- **CORS**: Cross-Origin Resource Sharing support
- **Observability**: Prometheus metrics, structured logging, distributed tracing
- **Admin API**: RESTful API for runtime management
- **Hot Reload**: Zero-downtime configuration updates
- **Protocol Support**: HTTP/1.1, HTTP/2, WebSocket, gRPC
- **Health Checks**: Active health checking for upstream targets
- **TLS**: TLS termination and mTLS support
