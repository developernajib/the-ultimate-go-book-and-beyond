## Web Dashboard

The web dashboard gives developers a visual interface to monitor their builds, view logs, and manage pipelines. Instead of using a heavy JavaScript framework, we use HTMX for dynamic interactions and Tailwind CSS for styling. HTMX lets you add AJAX-like behavior directly in HTML attributes, which keeps the frontend simple and avoids the complexity of a separate single-page application. The dashboard updates in real-time using WebSocket connections for log streaming and periodic polling for build status changes.
