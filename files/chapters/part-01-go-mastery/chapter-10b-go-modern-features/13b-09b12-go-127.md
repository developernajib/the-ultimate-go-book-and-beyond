## 10B.12 Go 1.27

Go 1.27 shipped August 2026 (baseline 1.27.1). The deep treatments live elsewhere in this book: generic methods in the Chapter 8 section "Go 1.27: Generic Methods", the full adoption posture in Chapter 6B Section 13, and the allocator details in Chapter 7's allocator deep-dive. This section is the quick reference for how 1.27 touches the features this chapter already covered.

### What 1.27 Changes for This Chapter's Features

| Feature (section) | 1.26 status | 1.27 status |
|---|---|---|
| json/v2 (10B.7) | `GOEXPERIMENT=jsonv2` opt-in | GA, and powers classic `encoding/json` |
| Goroutine leak profile (10B.6) | Experimental | GA in `runtime/pprof` and `net/http/pprof` |
| Green Tea GC (10B.5) | Default collector | Unchanged, joined by the size-specialized allocator (up to 30% cheaper small allocations) |
| go fix modernizers (10B.11) | 1.26 set | Adds `atomictypes`, `embedlit`, `slicesbackward`, `unsafefuncs`, removes `fmtappendf` |
| Post-quantum crypto (10B.10) | `crypto/hpke`, ML-KEM | Adds `crypto/mldsa` (FIPS 204 signatures), ML-DSA and `MLKEM1024` in `crypto/tls` |
| Iterators (10B.1) | `iter.Seq` ecosystem | Unchanged, easier to compose thanks to generalized function type inference |

### New in 1.27 Itself

- **Generic methods.** Methods can declare their own type parameters (interface methods still cannot). The headline language change of the release, covered in depth in Chapter 8.
- **Generalized type inference.** Generic functions assign to matching function-typed variables and parameters without explicit instantiation.
- **Stdlib `uuid` package.** Generation and parsing without the third-party dependency.
- **`strings.CutLast` / `bytes.CutLast`**, **`net/url.URL.Clone`**, **`net/http/httptest.NewTestServer`**, and `math/rand/v2`'s generic `Rand.N` method rounding out the v2 API this chapter covers in 10B.3.
- **Timer channel cleanup.** The `asynctimerchan` GODEBUG is gone, timer channels are always unbuffered. Code untouched since the 1.23 timer semantics change needs nothing.

### Adoption Note

With 1.27 shipped: run 1.27.1 in CI, benchmark the allocator on allocation-heavy services, and green-light public API designs around generic methods. Remove remaining "in preview" qualifiers from your team's docs.
