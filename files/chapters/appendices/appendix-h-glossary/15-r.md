## R

### Race Condition
Bug where program behavior depends on timing of uncontrolled concurrent events.

```go
// Race condition (use -race to detect)
var counter int
go func() { counter++ }()
go func() { counter++ }()
```

### Range
Keyword for iterating over arrays, slices, maps, strings, channels.

```go
for key, value := range myMap {
    fmt.Println(key, value)
}
```

### Receiver
Parameter before method name binding the method to a type.

```go
func (r *Rectangle) Area() float64 {
    return r.width * r.height
}
```

### Recover
Built-in function to regain control after a panic, must be called in deferred function.

```go
func safe() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered:", r)
        }
    }()
    panic("oops")
}
```

### Reference Type
Types that hold references to underlying data structures (slices, maps, channels).

```go
s1 := []int{1, 2, 3}
s2 := s1  // Both reference same backing array
s2[0] = 99
fmt.Println(s1[0])  // 99
```

### Reflection
Runtime inspection and manipulation of types and values via `reflect` package.

```go
v := reflect.ValueOf(42)
fmt.Println(v.Type())  // int
fmt.Println(v.Int())   // 42
```

### Rune
Alias for `int32`, represents a Unicode code point.

```go
var r rune = '世'
fmt.Printf("%c %U\n", r, r)  // 世 U+4E16
```

### Runtime
Package providing operations that interact with Go's runtime system.

```go
runtime.NumGoroutine()  // Active goroutines
runtime.GC()            // Trigger garbage collection
```
