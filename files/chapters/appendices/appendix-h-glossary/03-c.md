## C

### Cap
Built-in function returning the capacity of a slice, array, or channel.

```go
s := make([]int, 5, 10)
fmt.Println(cap(s))  // 10
```

### Channel
Typed conduit for communication between goroutines, core to CSP concurrency.

```go
ch := make(chan string)
go func() { ch <- "message" }()
msg := <-ch
```

### Close
Built-in function to close a channel, signaling no more values will be sent.

```go
ch := make(chan int)
close(ch)
v, ok := <-ch  // ok is false after close
```

### Closure
A function that references variables from its outer scope.

```go
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}
```

### Comparable
Types that can be compared with `==` and `!=` (booleans, numbers, strings, pointers, channels, interfaces, structs/arrays of comparable types).

```go
type Person struct { Name string }
p1, p2 := Person{"Alice"}, Person{"Bob"}
if p1 == p2 { /* ... */ }
```

### Composite Literal
Syntax for constructing values of structs, arrays, slices, and maps.

```go
p := Person{Name: "Alice", Age: 30}
s := []int{1, 2, 3}
m := map[string]int{"a": 1, "b": 2}
```

### Concurrency
Running multiple computations simultaneously, managed in Go through goroutines and channels.

```go
go doWork()  // Concurrent execution
```

### Constraint
An interface type used in generics to restrict type parameters.

```go
type Ordered interface {
    ~int | ~string | ~float64
}

func Max[T Ordered](a, b T) T {
    if a > b { return a }
    return b
}
```

### Context
Package and type for carrying deadlines, cancellation signals, and request-scoped values across API boundaries.

```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
```

### Copy
Built-in function to copy elements from source to destination slice.

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
n := copy(dst, src)  // Returns number copied
```
