## P

### Package
Directory of Go source files compiled together, the unit of code organization.

```go
package main

import "fmt"
```

### Panic
Built-in function that stops normal execution and begins unwinding the stack.

```go
if err != nil {
    panic("critical error")
}
```

### Parallelism
Simultaneous execution of computations on multiple CPU cores.

```go
runtime.GOMAXPROCS(4)  // Use 4 cores
```

### Pointer
Variable storing a memory address.

```go
x := 42
p := &x     // Pointer to x
*p = 100    // Modify through pointer
```

### Polymorphism
Different types satisfying the same interface.

```go
type Shape interface { Area() float64 }

func totalArea(shapes []Shape) float64 {
    var total float64
    for _, s := range shapes {
        total += s.Area()  // Polymorphic call
    }
    return total
}
```
