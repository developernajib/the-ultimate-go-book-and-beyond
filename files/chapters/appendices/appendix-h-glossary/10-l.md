## L

### Len
A built-in compile-time and runtime primitive that returns the number of elements in arrays, slices, maps, strings, and channels. For slices and strings, `len()` is an instantaneous $O(1)$ read of the second word in the header structure.

### Level-Triggered vs. Edge-Triggered
Two fundamental models of state synchronization. In edge-triggered systems, notifications are sent only when a state transition occurs (e.g. "order transitioned to paid"). If an edge event is dropped, the system remains out of sync. In level-triggered systems (the foundation of the Kubernetes reconciliation loop), controllers evaluate the desired state against the current state continuously until equilibrium is reached, making reconciliation naturally idempotent and fault-tolerant.

### Least Connections
A load balancing algorithm that routes incoming requests to the upstream server currently processing the fewest active concurrent connections. It outperforms simple round-robin routing in microservices where request processing durations exhibit high variance.

### Liveness & Readiness Probes
Kubernetes operational health probes. A **Liveness Probe** checks if the container process is functional; failing it causes the kubelet to restart the pod. A **Readiness Probe** checks if the application is prepared to accept network traffic (e.g. database connections initialized, warm caches populated); failing it removes the pod from the service endpoint pool without killing the process.

### Lock-Free Programming
Concurrent programming techniques that use hardware-level atomic instructions (`sync/atomic` CAS, Swap, Load, Store) instead of operating system mutexes to synchronize access to shared data. Lock-free data structures eliminate thread scheduling overhead, priority inversion, and context switches at the cost of higher algorithmic complexity.

### Literal
Source code notation representing fixed constant values. Go supports integer literals (`42`, `0x2A`), floating-point literals, rune literals (`'⌘'`), raw string literals (``...``), and composite literals for structs, arrays, slices, and maps (`&User{ID: 101}`).
