## H

### Happens-Before
A formal memory model relationship defining when the memory writes of one goroutine are guaranteed to be visible to the reads of another goroutine. In Go, initialization of a global variable happens-before `main.main()`; a send on an unbuffered channel happens-before the corresponding receive completes; a `sync.Mutex.Unlock()` happens-before any subsequent `Lock()` call returns; and a call to `sync.WaitGroup.Done()` happens-before any `Wait()` call returns. Without an explicit happens-before relationship, compilers and CPU hardware reorder instructions freely, producing data races.

```go
var data string
var ready = make(chan struct{})

func worker() {
    data = "processed"    // 1. Write happens-before channel send
    close(ready)          // 2. Channel close establishes synchronization point
}

func main() {
    go worker()
    <-ready               // 3. Channel receive establishes happens-before guarantee
    println(data)         // 4. Guaranteed to observe "processed"
}
```

### Hash Table (hmap & bmap)
Go's built-in `map` is implemented as an incremental hash table using an `hmap` header struct pointing to buckets (`bmap`). Each bucket holds up to 8 key-value pairs stored in separate key and value arrays (avoiding alignment padding). When the load factor exceeds 6.5, Go triggers an incremental rehashing process, allocating double the buckets and migrating entries gradually during subsequent writes to avoid latency spikes.

### Heap
The dynamic memory arena managed by Go's runtime and garbage collector. Memory escapes to the heap when the compiler's escape analysis cannot prove that a variable's lifetime is strictly bounded to the executing stack frame (e.g. returning a pointer to a local variable, storing values in `interface{}`, or slices with dynamically sized bounds).

### Header
Lightweight metadata structures used by the Go runtime to represent dynamic data types. A slice header consists of 3 machine words (Pointer, Len, Cap = 24 bytes on 64-bit). A string header consists of 2 words (Pointer, Len = 16 bytes). An interface header consists of 2 words (Type descriptor pointer, Data pointer = 16 bytes).

### Hot Path
The performance-critical execution loop of a service that handles the vast majority of requests (e.g. the matching loop in an exchange or the packet router in a proxy). High-performance Go engineering demands zero heap allocations, zero lock contention, and inlined function calls on the hot path.

### Hugepages
Linux virtual memory pages sized at 2MB or 1GB instead of standard 4KB pages. Using hugepages dramatically reduces Translation Lookaside Buffer (TLB) cache misses for memory-intensive services such as in-memory databases, caches, and high-frequency trading engines.
