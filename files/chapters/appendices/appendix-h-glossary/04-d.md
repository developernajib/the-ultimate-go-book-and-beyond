## D

### Deadlock
Situation where goroutines wait indefinitely for each other, causing the program to hang.

```go
// Deadlock example
ch := make(chan int)
<-ch  // Blocks forever: fatal error: all goroutines are asleep
```

### Defer
Statement that schedules a function call to run after the surrounding function returns.

```go
func process() {
    f, _ := os.Open("file.txt")
    defer f.Close()  // Executes after function returns
    // Work with file...
}
```

### Dereference
Accessing the value pointed to by a pointer using `*`.

```go
x := 42
p := &x
fmt.Println(*p)  // 42 (dereferenced)
```

### Directive
Special comments that provide instructions to the compiler or tools.

```go
//go:generate mockgen -source=interface.go
//go:noinline
//go:embed config.json
```

### Duck Typing
Go's implicit interface satisfaction: if a type has the required methods, it implements the interface.

```go
type Writer interface { Write([]byte) (int, error) }
// Any type with Write method satisfies Writer
```
