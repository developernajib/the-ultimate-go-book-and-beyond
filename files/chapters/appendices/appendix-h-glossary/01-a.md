## A

### Allocation
The process of reserving memory for variables, either on the stack (fast, automatic) or heap (slower, garbage collected).

```go
x := 42           // Stack allocation (typically)
p := new(int)     // Heap allocation
s := make([]int, 10) // Heap allocation for backing array
```

### Anonymous Function
A function without a name, often used as a closure or inline callback.

```go
func main() {
    greet := func(name string) {
        fmt.Println("Hello,", name)
    }
    greet("World")
}
```

### Any
Alias for `interface{}` introduced in Go 1.18, representing any type.

```go
var x any = "string"
var y any = 42
```

### Append
Built-in function to add elements to a slice, potentially allocating a new backing array.

```go
s := []int{1, 2, 3}
s = append(s, 4, 5) // [1, 2, 3, 4, 5]
```

### Atomic
Operations that complete indivisibly without interruption, used for lock-free synchronization.

```go
var counter int64
atomic.AddInt64(&counter, 1)
value := atomic.LoadInt64(&counter)
```
