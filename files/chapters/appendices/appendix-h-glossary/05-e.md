## E

### Embedding
Composing types by including one type inside another without a field name.

```go
type Logger struct { /* ... */ }
func (l *Logger) Log(msg string) { /* ... */ }

type Server struct {
    Logger  // Embedded
}

s := Server{}
s.Log("message")  // Promoted method
```

### Empty Interface
`interface{}` or `any`, satisfied by all types.

```go
var x any = "anything"
var y any = 42
```

### Empty Struct
Struct with no fields, occupies zero bytes, often used for signaling.

```go
type signal struct{}
done := make(chan struct{})
done <- struct{}{}
```

### Escape Analysis
Compiler analysis determining whether variables can be stack-allocated or must escape to the heap.

```go
func local() {
    x := 42  // Stack allocated
}

func escapes() *int {
    x := 42
    return &x  // Escapes to heap
}
```
