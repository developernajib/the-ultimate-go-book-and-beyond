## S

### Scheduler
Runtime component that multiplexes goroutines onto OS threads.

### Select
Statement for multiplexing channel operations.

```go
select {
case msg := <-ch1:
    fmt.Println(msg)
case ch2 <- value:
    fmt.Println("sent")
case <-time.After(time.Second):
    fmt.Println("timeout")
}
```

### Shadowing
Inner scope variable hiding outer scope variable with same name.

```go
x := 10
if true {
    x := 20  // Shadows outer x
    fmt.Println(x)  // 20
}
fmt.Println(x)  // 10
```

### Slice
Dynamic view into an array, with length and capacity.

```go
s := []int{1, 2, 3, 4, 5}
sub := s[1:4]  // [2, 3, 4]
fmt.Println(len(sub), cap(sub))  // 3 5
```

### Stack
Memory region for function call frames and local variables, automatically managed.

```go
func recursive(n int) {
    if n > 0 {
        recursive(n - 1)  // Stack grows
    }
}
```

### String
Immutable sequence of bytes, typically UTF-8 encoded text.

```go
s := "Hello, 世界"
fmt.Println(len(s))  // Bytes, not runes
```

### Struct
Composite type grouping fields together.

```go
type Person struct {
    Name string
    Age  int
}

p := Person{Name: "Alice", Age: 30}
```

### Struct Tag
String metadata attached to struct fields.

```go
type User struct {
    Name  string `json:"name" validate:"required"`
    Email string `json:"email" validate:"email"`
}
```
