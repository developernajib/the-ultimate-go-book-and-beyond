## B

### Backpressure
A flow-control mechanism where a downstream consumer signals an upstream producer to slow down or halt rate of production when buffers are full. In Go, backpressure is implemented naturally through bounded channels, `select` statements with default non-blocking drops, or token buckets.

```go
select {
case queue <- task:
    // Enqueued successfully
default:
    // Buffer full: apply backpressure (reject or rate limit)
    http.Error(w, "service overloaded", http.StatusServiceUnavailable)
}
```

### Backing Array
The contiguous block of heap or stack memory that holds the actual elements of a Go slice. A slice header references a backing array via a pointer word. When a slice appends beyond its capacity, the runtime allocates a new, larger backing array and copies existing elements over.

### Blank Identifier (`_`)
An anonymous variable used to discard values in multiple-assignment expressions, ignore unused package imports, or verify compile-time interface implementation:

```go
var _ io.Reader = (*CustomReader)(nil) // Compile-time interface check
```

### Bmap
The internal Go runtime struct (`runtime.bmap`) representing a single bucket in a Go hash map (`runtime.hmap`). Each bucket holds up to 8 key-value pairs stored in separate key and value arrays to minimize CPU alignment padding.

### Bounded Queue
A concurrent queue with an explicit maximum capacity. Bounded queues prevent out-of-memory cascading failures under burst traffic by bounding memory consumption at compile time.

### Branch Prediction
A CPU hardware optimization predicting which direction a conditional branch will take before the condition is evaluated. Mispredicted branches stall the instruction pipeline for 15–20 clock cycles. High-performance Go hot paths use branchless arithmetic to avoid prediction penalties.

### Buffered Channel
A channel initialized with non-zero capacity (`make(chan T, 100)`). Buffered channels decouple senders and receivers, allowing sends to proceed without blocking until the buffer ring is completely full.

### Build Tags (`//go:build`)
Compiler directives at the top of Go source files that dictate conditional compilation based on operating system, architecture, or custom tags:

```go
//go:build linux && amd64
package platform
```
