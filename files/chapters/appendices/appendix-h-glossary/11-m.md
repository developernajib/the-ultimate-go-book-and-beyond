## M

### Make
Built-in function for creating slices, maps, and channels with initialization.

```go
s := make([]int, 5, 10)     // len=5, cap=10
m := make(map[string]int)
ch := make(chan int, 5)
```

### Map
Built-in hash table type mapping keys to values.

```go
m := map[string]int{"a": 1, "b": 2}
m["c"] = 3
value, exists := m["a"]
```

### Method
Function with a receiver, associated with a type.

```go
type Counter struct { count int }

func (c *Counter) Increment() {
    c.count++
}
```

### Method Set
Set of methods associated with a type, determines interface satisfaction.

```go
type T struct{}
func (T) ValueMethod() {}
func (*T) PointerMethod() {}

// T has method set: {ValueMethod}
// *T has method set: {ValueMethod, PointerMethod}
```

### Module
Collection of Go packages versioned together, defined by `go.mod`.

```go
// go.mod
module github.com/user/project

go 1.27

require github.com/other/lib v1.2.3
```

### Mutex
Mutual exclusion lock for protecting shared data from concurrent access.

```go
var mu sync.Mutex
mu.Lock()
defer mu.Unlock()
// Critical section
```
