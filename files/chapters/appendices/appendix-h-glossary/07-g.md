## G

### Garbage Collection (Tri-Color Concurrent Mark-and-Sweep)
Go's automatic memory management subsystem. Go uses a non-generational, concurrent tri-color mark-and-sweep collector with sub-millisecond stop-the-world (STW) pauses:
- **White**: Unvisited objects; candidates for collection.
- **Grey**: Visited objects whose referenced children have not yet been scanned.
- **Black**: Visited objects with all referenced children scanned. Guaranteed live.

### GMP Scheduler
The Go runtime scheduling architecture multiplexing concurrent user-space execution:
- **G (Goroutine)**: Lightweight user-space thread with 2KB dynamic stack.
- **M (Machine)**: An operating system thread managed by the OS kernel.
- **P (Processor)**: A logical processor representing a resource required to execute Go code. The number of P's equals `GOMAXPROCS`.

```
┌────────────────────────────────────────┐
│             GMP Architecture           │
├────────────────────────────────────────┤
│   Local Run Queue (P) ────> [G1, G2]   │
│            │                           │
│            ▼                           │
│     OS Thread (M)                      │
└────────────────────────────────────────┘
```

### `GOMEMLIMIT`
A runtime environment variable introduced in Go 1.19 establishing a soft memory ceiling for the Go runtime. As heap allocations approach `GOMEMLIMIT`, the garbage collector triggers aggressive cycles, eliminating container OOMKilled evictions in Kubernetes.

### `GOMAXPROCS`
The runtime setting controlling the number of operating system threads that can execute user-level Go code simultaneously. Defaults to the number of visible logical CPU cores.

### Generics (Type Parameters)
Parametric polymorphism introduced in Go 1.18. Generics enable writing type-safe data structures and algorithms without sacrificing compile-time safety or resorting to `any` interface boxing:

```go
func Map[T any, R any](items []T, fn func(T) R) []R {
    out := make([]R, len(items))
    for i, v := range items {
        out[i] = fn(v)
    }
    return out
}
```

### Goroutine
A lightweight thread of execution managed entirely by the Go runtime scheduler. Goroutines start with a minimal 2KB stack that expands and shrinks dynamically in contiguous memory, allowing a single service to run millions of concurrent goroutines.

### Graceful Shutdown
An operational discipline where a terminating service intercepts OS signals (`SIGTERM`, `SIGINT`), stops accepting new incoming network connections, drains in-flight requests within a bounded deadline, and flushes database buffers before process exit.
