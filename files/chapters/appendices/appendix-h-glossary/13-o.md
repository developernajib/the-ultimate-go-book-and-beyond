## O

### OpenTelemetry (OTel)
The CNCF standard and unified SDK ecosystem for generating, collecting, and exporting vendor-agnostic distributed telemetry: distributed trace spans, application metrics, and structured logs.

### Operator
A symbol or keyword that specifies an action on one or more operands. Go features arithmetic operators (`+`, `-`, `*`, `/`, `%`), comparison operators (`==`, `!=`, `<`, `>`), bitwise operators (`&`, `|`, `^`, `&^`), logical operators (`&&`, `||`, `!`), and communication operators (`<-` for channels).

### Optimistic Concurrency Control (OCC)
A concurrency pattern that allows multiple transactions to proceed without locking database rows, verifying at commit time that the record version has not changed. In Go, OCC is typically implemented with version numbers: `UPDATE accounts SET balance = ?, version = version + 1 WHERE id = ? AND version = ?`.

### Outbox Pattern (Transactional Outbox)
An enterprise distributed systems resilience pattern where domain state changes and outbound event messages are written to the same database inside a single atomic transaction. A dedicated background publisher poll/tail routine reads the outbox table and dispatches events to message brokers (Kafka/RabbitMQ), guaranteeing reliable delivery without two-phase commit (2PC) distributed transactions.

### OOM (Out Of Memory)
An operating system condition where the kernel kills processes (via the OOM Killer) to prevent kernel panic when memory exhaustion occurs. In Go 1.19+, setting the `GOMEMLIMIT` environment variable instructs the garbage collector to trigger aggressive collections as heap memory nears the specified ceiling, drastically reducing container OOM termination events.

### `sync.Once`
A concurrency primitive that guarantees a function runs exactly once regardless of how many concurrent goroutines call it. Implemented using an atomic fast-path load and a slow-path `sync.Mutex` with double-checked locking:

```go
var (
    dbInstance *sql.DB
    dbOnce     sync.Once
)

func GetDB() *sql.DB {
    dbOnce.Do(func() {
        dbInstance = initDatabaseConnection()
    })
    return dbInstance
}
```
