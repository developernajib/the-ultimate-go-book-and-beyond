## U

### Unbuffered Channel
A channel created with zero buffer capacity (`make(chan T)`). In an unbuffered channel, sending and receiving operations are completely synchronous: a sender blocks until a receiver is ready to receive the value, and a receiver blocks until a sender publishes. This establishes an explicit happens-before synchronization boundary between goroutines.

### Unsafe Package
Go's built-in `unsafe` package provides operations that bypass the language's compile-time type safety guarantees. By utilizing `unsafe.Pointer` and `uintptr`, engineers can perform direct pointer arithmetic, inspect struct padding, and convert memory buffers with zero allocations. Code utilizing `unsafe` is non-portable and susceptible to breaking changes across Go compiler versions.

### Untyped Constants
Constants declared in Go without an explicit type (e.g., `const MaxLimit = 1000`). Untyped constants possess arbitrary precision (beyond standard 64-bit bounds) and implicitly adopt the type required by the context in which they are used, eliminating unnecessary type casting.

### Unit Test
Automated verification testing individual functions or packages in isolation. In Go, unit tests are written in files ending in `_test.go` using the standard library's `testing` package, run via `go test ./...`.

### User-Space Threading (M:N Model)
A concurrency model where the runtime scheduler multiplexs $M$ lightweight user-space threads (goroutines) across $N$ kernel-level OS threads. Go's GMP scheduler manages context switches in user space within tens of nanoseconds, bypassing the microsecond overhead and 2MB default stack footprint of OS kernel threads.
