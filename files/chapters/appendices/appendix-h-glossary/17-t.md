## T

### Type Alias
Alternative name for an existing type.

```go
type MyInt = int  // Alias, same type
type MyInt2 int   // New type, different
```

### Type Assertion
Extracting concrete value from interface.

```go
var i any = "hello"
s, ok := i.(string)  // Type assertion
if ok {
    fmt.Println(s)
}
```

### Type Constraint
Interface defining allowed types for generic type parameters.

```go
type Number interface {
    ~int | ~float64
}

func Sum[T Number](values []T) T {
    var sum T
    for _, v := range values {
        sum += v
    }
    return sum
}
```

### Type Parameter
Generic type variable in function or type definitions.

```go
func Map[T, U any](s []T, f func(T) U) []U {
    // T and U are type parameters
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}
```

### Type Switch
Switch statement discriminating on interface type.

```go
switch v := i.(type) {
case int:
    fmt.Println("int:", v)
case string:
    fmt.Println("string:", v)
default:
    fmt.Println("unknown")
}
```
