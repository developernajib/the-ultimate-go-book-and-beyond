## V

### Value Receiver
A method defined with a value parameter rather than a pointer (e.g., `func (u User) FullName() string`). When a method with a value receiver is invoked, Go passes a complete copy of the struct to the method. Any modifications made to fields inside the method operate on the local copy and do not affect the caller. Value receivers are preferred for small, immutable types or types that model primitive values.

### Variadic Function
A function that accepts zero or more arguments for its final parameter, denoted with an ellipsis (`...`). Within the function body, the variadic parameter is treated as a slice of the specified type:

```go
func Sum(numbers ...int) int {
    total := 0
    for _, n := range numbers {
        total += n
    }
    return total
}
```

### Vectorization (SIMD)
Hardware capability executing a single instruction across multiple data points simultaneously (Single Instruction, Multiple Data). In high-performance Go, vectorization is utilized internally in packages like `bytes`, `crypto`, and string searching routines.

### Vtable (Virtual Method Table)
The runtime lookup table used in languages like C++ to implement dynamic dispatch for virtual functions. In Go, interface dispatch uses an **itable** (interface table) containing the type descriptor and the list of method pointers that satisfy the interface.
