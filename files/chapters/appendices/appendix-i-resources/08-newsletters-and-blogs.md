### 2025, 2026 Online Resources

The following resources are particularly relevant for staying current with modern Go development practices:

#### go.dev/blog - Official Go Blog

**URL**: https://go.dev/blog
**RSS**: https://go.dev/blog/feed.atom

The authoritative source for Go news. Covers release announcements (Go 1.25, 1.26, 1.27), deep dives into new language features, GC design decisions, and production case studies. Subscribe via RSS to receive Go 1.26+ release notes and toolchain updates directly. Must-read for any developer writing production Go.

#### github.com/avelino/awesome-go - Curated Go Resources

**URL**: https://github.com/avelino/awesome-go
**Stars**: 130K+

The largest curated list of Go frameworks, libraries, tools, and resources. Organized by category (web frameworks, databases, testing, CLI, networking, etc.). Updated continuously by the community. Invaluable for discovering well-maintained libraries before reinventing wheels. Check the "Recently Updated" filter to find actively maintained projects.

**Usage Pattern**: Before adding a new dependency, search awesome-go to compare alternatives. Check last commit date and star count for maintenance signal.

#### bytesizego.com - Go Newsletter (2025, 2026)

**URL**: https://www.bytesizego.com
**Frequency**: Weekly
**Cost**: Free

A focused Go newsletter launched in 2024, covering Go internals, performance optimization, and production patterns. Especially strong on Go runtime behavior, escape analysis, and profiling - topics that help developers write more efficient Go code. Recommended for intermediate-to-advanced developers who want concise, actionable Go content beyond syntax tutorials.

#### threedots.tech - Advanced Go Patterns Blog

**URL**: https://threedots.tech
**Focus**: Clean architecture, DDD, and production Go patterns

A technical blog by the authors of Watermill (a Go event-driven framework). Covers advanced patterns including:
- Domain-Driven Design in Go
- CQRS and event sourcing implementations
- Clean architecture with Go
- Testing strategies for complex business logic
- Real-world microservices patterns

**Why Follow**: Most Go resources focus on syntax or standard library. Threedots.tech addresses the harder question: how do you structure large Go applications that remain maintainable at scale? Their "Building a Robust App in Go" series is required reading for any developer designing production systems.
