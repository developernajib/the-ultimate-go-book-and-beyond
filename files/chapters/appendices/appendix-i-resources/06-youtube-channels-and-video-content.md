## YouTube Channels and Video Content

### GopherCon Talks

**URL**: https://www.youtube.com/@GopherConEurope
**Content**: Conference presentations
**Level**: All levels

**Why Watch**: The main Go conference with talks from Go team members and expert practitioners. High-quality, in-depth presentations.

**Must-Watch Talks**:

1. **"Concurrency Is Not Parallelism"** - Rob Pike (2012)
 - Fundamental concepts of concurrency
 - Go's approach to concurrent programming

2. **"Understanding Channels"** - Kavya Joshi (2017)
 - How channels work internally
 - Performance characteristics

3. **"The Scheduler Saga"** - Kavya Joshi (2018)
 - Go scheduler internals
 - Performance implications

4. **"Simplicity is Complicated"** - Rob Pike (2015)
 - Go's design philosophy
 - Why simplicity matters

5. **"Go Proverbs"** - Rob Pike (2015)
 - Idiomatic Go wisdom
 - Design principles

6. **"Advanced Testing Patterns"** - Mitchell Hashimoto (2018)
 - Real-world testing strategies
 - Table-driven tests and helpers

7. **"Production Grade gRPC"** - Alan Shreve (2021)
 - gRPC in production
 - Reliability patterns

**Browsing Strategy**:
1. Start with keynotes for big-picture understanding
2. Watch talks relevant to your current work
3. Explore advanced topics as you grow
4. Return annually for new conference content

### JustForFunc

**URL**: https://www.youtube.com/c/JustForFunc
**Host**: Francesc Campoy (former Go team member)
**Content**: Programming challenges, code reviews, Go tutorials
**Status**: Archive (no new content, but valuable)

**Why Watch**: Practical, hands-on Go programming with excellent explanations.

**Series**:
- **Programming Challenges**: Solving problems in Go
- **Code Reviews**: Reviewing real Go code
- **Go Tooling**: Using Go tools effectively
- **Algorithms in Go**: Implementing classic algorithms

**Notable Episodes**:
- "Understanding nil"
- "Context package deep dive"
- "Implementing a simple database in Go"
- "Go tooling masterclass"

**Best For**: Intermediate developers who want to see real problem-solving in Go.
