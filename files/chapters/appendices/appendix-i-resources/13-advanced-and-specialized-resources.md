## Advanced and Specialized Resources

### Performance and Optimization

#### "Profiling Go Programs" (Official Blog)

**URL**: https://go.dev/blog/pprof
Essential guide to profiling with pprof.

#### High Performance Go Workshop

**Author**: Dave Cheney
**URL**: https://dave.cheney.net/high-performance-go-workshop
**Format**: Workshop materials freely available

**Coverage**:
- Benchmarking
- Profiling (CPU, memory, block, mutex)
- Compiler optimizations
- Execution tracer
- Memory and garbage collector

#### "Optimization Tips" (Ardan Labs)

Various blog posts on performance optimization.

#### The Go Memory Model

**URL**: https://go.dev/ref/mem
**Level**: Advanced

Understanding memory guarantees and synchronization.
