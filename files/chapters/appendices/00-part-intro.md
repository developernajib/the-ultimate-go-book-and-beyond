# Appendices

*The value of a reference is not that you read it cover to cover. It is that you know exactly where to look when you need it.*

---

The appendices collect reference material for everything covered in this book. The main chapters teach concepts through progressive learning. The appendices provide quick-lookup resources, question banks, tool references, and cheat sheets for daily use.

Each appendix is self-contained. Use the company deep dives before a specific interview. Use the question bank for structured practice. Reference the tools and standard library appendices when setting up projects. Keep the quick reference and production pitfalls appendices bookmarked for daily use.

**What this part covers:**
- Appendix A: Company Deep Dives - how Google, Meta, Amazon, Netflix, Uber, and other top companies use Go in production
- Appendix B: Interview Questions - question bank organized by topic and difficulty level
- Appendix C: Tools Reference - essential Go development tools, IDE setup, linters, and productivity utilities
- Appendix D: Standard Library Reference - key packages from Go's standard library with usage examples
- Appendix E: Common Patterns - design patterns implemented idiomatically in Go
- Appendix F: Performance Tuning - optimization checklist and tuning guide for production Go services
- Appendix G: Migration Guides - transitioning to Go from Python, Java, JavaScript, Rust, and C++
- Appendix H: Glossary - definitions of terms used throughout the book
- Appendix I: Resources - recommended books, blogs, courses, conferences, and community resources
- Appendix J: Version Changelog - Go version history with feature additions and breaking changes
- Appendix K: Quick Reference - cheat sheets for syntax, common operations, and frequently used patterns
- Appendix L: Production Pitfalls - common mistakes in production Go code and how to avoid them

**How to use this part:**
These appendices are not meant to be read sequentially. Treat them as a searchable reference: jump to whichever appendix matches your current need.
