## Go 1.19 (August 2022)

### Refined Memory Model

Clarified happens-before relationships for atomic operations and sync primitives. Aligned with C++, Java, JavaScript, Rust, and Swift memory models.

```go
import "sync/atomic"

var x, y atomic.Int64

// Goroutine 1
func writer() {
    x.Store(1)
    y.Store(1) // Guaranteed to be visible after x.Store(1)
}

// Goroutine 2
func reader() {
    for y.Load() == 0 {
        // Spin
    }
    // x.Load() is guaranteed to return 1
    fmt.Println(x.Load())
}
```

### Atomic Types

Type-safe atomic operations without pointer conversions.

```go
// Before Go 1.19
var counter int64
atomic.AddInt64(&counter, 1)
val := atomic.LoadInt64(&counter)

// Go 1.19+
var counter atomic.Int64
counter.Add(1)
val := counter.Load()

// All atomic types
var (
    i32  atomic.Int32
    i64  atomic.Int64
    u32  atomic.Uint32
    u64  atomic.Uint64
    up   atomic.Uintptr
    b    atomic.Bool
    p    atomic.Pointer[MyType]
)

// Atomic pointer with type safety
type Config struct {
    MaxConns int
}

var config atomic.Pointer[Config]
config.Store(&Config{MaxConns: 100})
cfg := config.Load()
fmt.Println(cfg.MaxConns) // No type assertion needed
```
