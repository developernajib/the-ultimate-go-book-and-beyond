### Technical Prerequisites

Before starting this part, you should be comfortable with:

- Go concurrency (Part II) - goroutines, channels, select
- Production patterns (Part III) - graceful shutdown, error handling, resilience
- Microservices basics (Part VIII) - service communication, event-driven architecture concepts
- Docker & Kubernetes basics (Part XV) - for running message brokers locally and in production
