## Learning Objectives

By the end of this chapter, you will:
- Design event-driven systems with proper event schemas and versioning
- Implement event streaming with Kafka in production Go services
- Build reliable event consumers with exactly-once processing
- Apply the Event-Carried State Transfer and Event Notification patterns
- Implement backpressure, dead-letter queues, and poison pill handling
- Design for event schema evolution without breaking consumers
