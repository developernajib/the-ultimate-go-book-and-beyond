## Learning Objectives

1. **Set up and use go generate** for code generation in a Go project
2. **Generate enums, mocks, and type-safe SQL** using standard tools
3. **Write a custom code generator** using go/ast and go/format
4. **Load Go plugins at runtime** with all their restrictions understood
5. **Bundle any file type into a Go binary** using embed and serve it efficiently
6. **Implement dependency injection** manually and with Wire/Dig
7. **Choose the right serialization format** for different use cases and performance requirements

### Detailed Outcomes

**Senior engineer**

- Adopt `go generate` for mocks, stringers, protobuf compilation.
- Decide when to use plugin vs link-time composition.
- Use embed appropriately, avoiding over-embedding.

**Staff or Principal**

- Drive org-wide code generation standards.
- Decide serialization formats as architectural choice.
- Own dependency injection policy (manual vs framework).
